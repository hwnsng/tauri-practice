# Tauri 연습

Tauri 2 + React + TypeScript로 데스크톱 앱 기능을 연습한 프로젝트입니다.

## 연습한 내용

- 커스텀 타이틀바와 창 최소화, 최대화, 숨기기
- 창을 항상 위에 표시하는 기능
- 시스템 트레이 메뉴로 앱 열기, 숨기기, 종료하기
- 별도의 투명한 오브 창 표시 및 숨기기
- 창 사이에 이벤트를 전달해 오브 상태 변경하기
- 창 위치 조회 및 변경, Store 플러그인으로 좌표 저장하기
- React에서 Rust 명령을 호출하는 invoke 사용하기
- 폴더 내 파일 목록 조회, 파일명 검색, 파일 열기 및 삭제
- React Router로 메인 화면과 오브 화면 분리하기

## 실행

- Node.js와 Rust, Tauri 개발 환경 설치
- npm install
- npm run tauri dev
